# SocialPulse AI — SIH 2026

> **AI-Powered Social Media Intelligence & Narrative Analysis Platform**  
> Built for commercial-grade real-time conversational intelligence, sentiment quantification, influencer network topology, and cross-platform narrative tracking.

---

## 🚀 Key Modules & Capabilities

- 📊 **Social Intelligence Overview**: Real-time AI executive briefing, high-level KPIs, sentiment polarity donuts, 14-day volume area chart, and live classified social feed.
- 🌐 **Platform Connector Hub**: Multi-platform connector management (X/Twitter, Reddit, Telegram, YouTube, Instagram, LinkedIn) with live stream status and webhook configuration simulator.
- 🗄️ **Data Ingestion & Monitor**: Telemetry terminal with live streaming logs, throughput rate metrics (342 msgs/sec), and interactive CSV/JSON batch dataset ingestion simulator.
- ❤️ **Sentiment & Emotion Intelligence**: 14-day multi-line sentiment trend, 6-emotion spectrum bars, Aspect-Based Sentiment Analysis (ABSA) for 5 product pillars, keyword weights, and filterable post explorer.
- 👥 **Audience & Demographics**: Age cohort distribution, gender split, geographic distribution with localized sentiment scores, language spread, and 4 unsupervised AI behavioral persona clusters.
- 📈 **Trend Intelligence & Radar**: Early warning anomaly alerts, lifecycle stages (*Emerging*, *Rising*, *Peaking*, *Saturated*, *Declining*), sparklines, and entity inspection drawers.
- 🕸️ **Network & Influence Intelligence**: Interactive SVG Social Topology Graph Map with zoom/pan controls, PageRank & betweenness centrality inspector, and Louvain community partitions.
- 🔀 **Information Flow & Cascade**: Multi-stage narrative diffusion stepper with interactive simulation player and cross-platform cascade hop matrix.
- ⏱️ **Conversation Timeline**: Dual-axis volume and sentiment correlation composed chart with annotated inflection point cards (Announcements, Viral Spikes, Controversies, Milestones).
- 🧩 **Cross-Platform Matrix**: Platform comparison metrics, share of voice, tone and format breakdowns, plus narrative mutation & framing divergence analysis.
- 🤖 **AI Copilot**: Conversational assistant with preset suggestions, verified social citations, inline chart insights, and interactive navigation actions.
- 📄 **Intelligence Reports Studio**: Report generator with custom section configuration, archive list, report preview modal, and PDF/Slide export simulation.

---

## 🛠️ Tech Stack & Architecture

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Custom Dark Glassmorphism Design System
- **Animations**: Framer Motion
- **Visualizations**: Recharts, SVG Topological Graph Engine
- **Icons**: Lucide React
- **API Architecture**: Typed asynchronous service abstraction layer (`src/services/api.ts`) for seamless 1-to-1 backend REST/GraphQL drop-in.

### 1. Install Dependencies
